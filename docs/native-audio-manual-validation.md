# Folia 0.7.9 原生音频修复版：人工验证

这是整合官方 v0.7.9 的 Windows x64 完整测试版，包含 WASAPI 独占、ASIO、整数 PCM 模式、ReplayGain、信号链界面及本轮修复。无需 Node、.NET SDK 或开发服务器。请将 ZIP **完整解压**到独立目录，再运行 `Folia Native Validation.exe`；不要只复制 exe。

使用独立配置目录 `%APPDATA%\FoliaNativeManual-20260929`。已有正式版音乐库和登录配置不会自动复制，首次使用请重新导入音乐目录或配置在线源。本包不包含账号、凭据、用户曲库或自动测试 profile。测试版关闭应用自动更新，避免官方版本覆盖待验证功能。

## 建议人工顺序

1. 设置 → 音频，先以浏览器后端确认普通播放。选择平时使用的真实音乐，检查导入、搜索、切歌、暂停和拖动进度。
2. 切到 WASAPI 独占，选择实际 DAC；再切到 ASIO 和对应驱动。先使用普通处理模式。确认声音、左右声道、音量、暂停后设备释放和恢复是否正常。
3. 分别启用整数模式，查看链路中的采样率、位深、处理模式和 effective gain。测试中已覆盖 XingCore，其他驱动仍需要您的实际听音验证。
4. ReplayGain 分别选择关闭、曲目、专辑。使用带真实标签的文件，比较切歌前后响度，关闭和重新启动后再播一次。
5. Navidrome 首次启动立即播放、连续切歌、暂停后恢复；重点听 `HUMMING LIFE — Spica`、`ピコ — 桜音`。两份现有 FLAC 存在帧损坏，严格转码拒绝是预期结果；能容错播放不代表文件完整。观察失败后下一首能否正常继续。
6. 在线源请在本人账号下检查网易云、QQ、酷狗的常用曲目；切换网络或出现失效链接后观察提示、续播位置和暂停意图。
7. 组件管理中可验证更新／回退。此包自带经过哈希核验的离线候选；此入口专供人工测试，官方版本仍只接受经 Folia 官方清单批准的组件。

遇到异常请记录曲目、来源、后端／设备、处理模式、发生时间、是否首次播放和复现步骤，并保留截图及 `%APPDATA%\FoliaNativeManual-20260929\logs` 下当时日志（若有）。分享前去掉账号凭据或带授权参数的 URL。自动测试通过不替代真实听音，也没有证明 DAC 输出位完美。
