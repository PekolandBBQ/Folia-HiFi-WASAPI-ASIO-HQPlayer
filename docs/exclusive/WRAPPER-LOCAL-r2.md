# Folia HiFi 0.7.12 本地修订 r2 — Wrapper

本包保留上游应用版本 0.7.12。整合基线为用户保存的 r37，Wrapper 是 Spotify 当前主线。HTTP 与 Origin 保持搁置。仅在本地生成安装包与免安装包，不发布 GitHub。

## 本次可见变化

- Spotify 桌面客户端本机控制、目录和实时采集接入完整 Folia；可使用 WASAPI、ASIO、HQPlayer 与整数模式。
- 检测普通桌面版和 Microsoft Store 版 Spotify。未安装时提示用户自行安装、登录。
- 固定版本组件一键安装之后紧接一键配置；已有组件与备份继续沿用。首次 VB-CABLE 安装提示重启并重新检查；默认输出落在虚拟线缆时引导选择实际扬声器或 DAC。
- 可后台拉起 Spotify，左下角显示准备进度；桌面换歌后自动暂停，选择追随或交还 Spotify 播放。退出或更换音源时询问是否关闭 Folia 拉起的 Spotify。
- 已点赞歌曲使用九首歌曲封面的拼贴，回传可用的 Spotify 原歌曲歌词。
- 采集过程中位置连续的不连续标记继续交付；已知缺口不超过 100 毫秒时补入等长静音。保留收到的原始整数样本，日志单独记录补偿帧数；较大或未知缺口仍报错。无强制跳进度和采集自动重建。

## 使用和适用范围

Windows x64 本地验证包，路由组件当前仅匹配 Windows 10.0.28000 的既定验证配置；其他系统构建不宣称已验证。普通桌面版检测有代码验证，本轮实际运行的是 Store 版 Spotify。Spotify 音量由用户管理，向导不自动读取或更改。

保持现有配置目录 Folia HiFi；卸载保留配置。免安装 ZIP 解压后运行，用户配置仍保存在 AppData，不随程序包携带。Spicetify 2.45.3、VB-CABLE Pack45/3.3.1.7、路由 0.19.0-dev.25、采集 0.1.5-capture.9 是此组件组合。首次完整 Spicetify 安装在全新 Windows 尚无实测环境；已有系统未重新安装或重跑 backup。

## 真实验证与保留事项

新采集组件在完整 Folia 实播 everscape 至自然结束并进入下一首：一次位置连续的不连续标记未停播。下一首出现 3440 帧（约 78 毫秒）缺口，补入静音后继续交付；后来默认输出短时变成 CABLE，既有输出检查停止播放。退出精确恢复 Spotify 原角色路由并关闭由 Folia 拉起的 Spotify；全局默认没有由 Folia 写入。该输出变化单独保留，随后读回为 LG TV。

本轮新改动的设备外测试20项、格式回读9项、宿主及相关回归219项通过；整合树类型检查与renderer构建通过。原 r37 复制树全量单测205项失败，整合树首次全量134项失败，后续快照修正记录另存。大量旧 HTTP/音量恢复测试与当前规则不一致；仍有缺失模型夹具和未更新界面测试。不得宣称全量CI通过或通用Windows生产资格通过。

HQPlayer、ASIO/WASAPI切换、整数模式、QQ/网易云/本地跨源、封面、原歌词和桌面协同沿用本次接入已保存的分阶段实播证据，保留各自组件版本与日期；按用户指示不重跑整套矩阵。

三秒性能及偶发Seek失败保留后续观察，本次不作为验收门槛。旧 dev.23 CAPTURE_DISCONTINUITY 失败记录仍保留；底层触发原因尚未唯一定位，短缺口容错不等同根因修复。补入静音的区间不称 bit-perfect。

最终整合树全量检查：6978通过、125失败、2跳过，16个文件失败与1个未处理错误；未记全量通过。另已对齐歌单封面、原歌词只读回传和明确预缓冲描述的旧测试夹具，75+15项通过。
