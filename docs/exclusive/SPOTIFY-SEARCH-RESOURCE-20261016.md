## 改动
- Store 发现记录读取 Spotify.exe 文件版本，不把 Store 包版本 1.305.x 当客户端 1.3.5 比较。
- 首次配置记录客户端版本；旧回执从 [Backup] version 读取，无需覆盖旧回执。
- 已知错配不再视为配置就绪，也不再用旧备份 apply 新客户端。自动配置为当前版本创建单独目录；新目录的首次 backup/apply 不修改原目录、原备份或 Spotify 安装目录。同一新目录失败后仍按既有回执续接，避免重跑原备份。
- 组件包升级与 Spotify 客户端升级分开判断。
- 握手、状态、目录和搜索不排在播放指令后面。播放指令总等待上限 8 秒，含排队时间；超时释放队列。晚到的 Seek 不能继续触发 Play。已经交给 Spotify 的单条原生指令无法由 JS 撤销，后续播放仍需既有状态回读确认。
- 新连接有独立控制队列；握手增加 independentReads 能力，旧运行中桥接将由既有自动连接流程更新。
- 运行日志补充资源版本、桥接请求失败操作与搜索返回数量，不记录查询词或令牌。
