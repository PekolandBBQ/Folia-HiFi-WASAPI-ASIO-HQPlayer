## 修改

- 清理 Promise 只合并进行中的操作；任何失败都结束本次尝试，不永久缓存拒绝结果。
- 自动路由失败保留清理所需控制器和路由，以状态决定是否释放，不再以错误码白名单决定是否可以再次核对。
