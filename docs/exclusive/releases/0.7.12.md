# Folia HiFi 0.7.12

合并上游稳定版 `v0.7.12`（`7f2ee0d50fab60518270cafb222c3c42688d3211`），专版应用版本同步为 **0.7.12**，发布标签为 `hifi-v0.7.12`。WASAPI/ASIO 与 HQPlayer 组件均保持各自独立的 **0.1.2**，不覆盖旧发行件。

## 专版更新

- 切换浏览器、WASAPI、ASIO 与 HQPlayer 输出保留当前歌曲、位置及播放／暂停意图；正在播放时自动继续。HQPlayer 在建立新播放流程后恢复检查点，避免启动操作将位置清零。
- 音频链路和 HQPlayer 按钮采用更紧凑的高度、字号与间距；鼠标进入进度条区域后随播放控件展开向下收起，离开后自然恢复，减少歌词遮挡。
- 音频详情、HQPlayer 设置、下拉菜单和加载提示统一为明暗主题毛玻璃表面；详情展开与关闭带过渡，遵守减少动态效果偏好。
- HQPlayer 连接后预读设置；再次打开使用完整缓存内容，同时刷新外部调整，避免每次展示空白加载面板。会话变化时失效，不为预读另行启动 HQPlayer。
- 仅在 HQPlayer 浮窗设置添加“显示 HQPlayer 窗口”滑动开关。显示／隐藏保留同一实例及音乐播放；与下次启动是否静默的偏好分开。
- 升频路径显示 PCM／DSD 前缀，例如 `PCM 44.1 kHz → PCM 384 kHz`、`PCM 48 kHz → DSD 1024`，使用实际引擎回报；未回报时仍明确显示未知。

## 上游与验证

包含上游 0.7.10 至 0.7.12 的改动，包括播放淡入淡出、新歌词与字幕处理、Lumière 可视化以及 Folium 1.4 音源扩展。上游署名、许可证与发行说明保留。

本次验证记录见 [验证报告](../VALIDATION.md) 与发行附件。当前测试设备为 Windows x64、HQPlayer Desktop 6、XingCore DAC；播放进度和窗口状态验证不等于主观音质比较。HQPlayer 定位受官方整秒接口及 DSP 预热限制，输入输出硬件仍在 Desktop 中配置。

首次流媒体仍需完整准备文件，等待时间随源站、缓存、DSP 与设备状态变化。退出 DSD 后设备端点可能暂时重新枚举，相关观察与失败记录保留于测试证据。

发行包不含 HQPlayer Desktop 或其许可证；专版组件批准清单不等于上游已合入或批准镜像来源。
