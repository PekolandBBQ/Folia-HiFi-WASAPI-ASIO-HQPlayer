# Folia HiFi 0.7.19 r1 · Spotify 接入与首次配置修复

正式标签：`folia-hifi-v0.7.19-r1`。应用版本随上游保持 **0.7.19**；上一正式发行件为 **0.7.12 r4**，旧标签与附件保留。

## 从上一版本到现在

- 同步上游稳定版 0.7.19，包含 Bravais 歌手与专辑海报、播放失败原因分类、中文/日文歌词分词、账户控制器与 Library v2；保留本 fork 的 Spotify Wrapper、WASAPI/ASIO、HQPlayer、整数 PCM、流式输出及短缺口容错。
- 修复首次 Spicetify 配置遗漏：Store 版备份的隐藏确认不再阻塞；私有资源副本包含预处理必需的程序和 V8 snapshot；Store 版正确使用 AppX 输出，官网桌面版使用 Apps 输出。已配置的用户不重跑 backup/apply。
- 每次安装前联网读取 Folia 最新已验证的统一组件清单；已有组件逐文件校验，版本一致且完整才复用。缺失或损坏的组件目录保留后重新准备；核对实际 VB-CABLE 驱动版本，同版不重复安装。新原生组件组合需要匹配的 Folia 时明确提示更新应用。
- 适配上游合并后的播放时序：避免元数据导致重复 Seek 0、准备阶段丢失播放意图，以及新曲解析时切换输出重新打开旧曲。Bravais 首页搜索与异步设置定位已修复。
- 修复“完成并返回歌单”时平台切换确认被安装向导挡住的问题；确认和取消都可正常操作，取消保留已完成的配置。

## 安装与使用

1. 正常退出旧 Folia，下载安装 EXE 或完整解压 ZIP。两者共用 `%APPDATA%\Folia HiFi`，已有配置与备份保留；不要同时运行两种程序。
2. 自行安装官网桌面版或 Microsoft Store 版 Spotify，启动并登录后退出。Folia 不代为安装 Spotify，也不查询或修改 Spotify 音量。
3. 在“连接 Spotify”选择要连接的安装，联网后按 **① 一键安装 → ② 一键配置** 完成准备。已经检测到组件仍会检查版本与文件完整性。
4. 首次安装或更新 VB-CABLE 驱动后按向导重启 Windows，再重新检查。Windows 默认输出选择实际扬声器或 DAC；不要选择 CABLE Input / CABLE In 16ch。
5. 点击“启动并连接 Spotify”，就绪后“完成并返回歌单”。需要 HQPlayer 时安装并授权 Desktop、设置 DAC/DSP 与网络控制，然后在 Folia 选择 HQPlayer 输出。

修正后的统一组件包为 **0.1.0-preview.4**：Spicetify 2.45.3、VB-CABLE 3.3.1.7、route26/capture9。清单作为 `spotify-wrapper-components.json` 随 Release 提供。它代表 Folia 已验证的组合，并非自动追逐第三方未经验证的新版本。

r4 的首次备份中断记录仍保留；本版在新的私有资源目录执行自己的首次配置，不覆盖原备份。已完成的旧配置继续复用。暂停、停止、Seek、切歌及后端切换保留路由；退出 Folia、实际播放其他音源或明确交还 Spotify 播放时恢复。
