# Folia HiFi 0.7.19 r5 · 双源应用更新与 Spotify 启动恢复

## 新功能与改进

- 启动后后台检查本 fork 的正式发行版；新增 GitHub、Gitee 和自动选择更新来源。国内用户可选择 Gitee，不查询上游发行版，不阻塞播放。
- 安装版支持应用内下载安装包，由用户确认后正常退出、更新并重新打开；便携版提供完整 ZIP 下载。增加内部构建编号，支持识别同版本覆盖更新。
- Spotify 首次冷启动保留真实失败原因并接入既有恢复流程，临时失败自动重试三次；补齐端点状态和恢复阶段日志。
- 修复恢复上次 Spotify 歌曲时底部播放入口未发出有效播放请求的问题；连接准备期间保留播放意图，左下角显示加载 Spotify、建立握手与握手成功进度。
- Spotify 更新后根据实际客户端版本检查外部资源，避免复用不同版本资源；改善桥接请求队列，减少搜索被其他请求阻塞的情况。
- 切换流媒体源时默认保留 Spotify，不再询问是否关闭。Spotify 连接设置新增“退出 Folia 时自动退出 Spotify”，默认关闭；退出不被恢复提示阻止。
- 音频链路显示设置独立列出，与 WASAPI/ASIO 设置同级。

## 双源与更新方式

应用版本为 0.7.19，专版标签为 `folia-hifi-v0.7.19-r5`。GitHub 和 Gitee 发布同一次构建的 EXE、ZIP 和 `folia-hifi-update.json`；Gitee 从 r5 开始保留发行版，源码结构与介绍保持一致。后续版本按此规则同步。

旧版本首次升级仍可手动下载 EXE 或 ZIP；支持新版更新器的安装版可直接检查、下载、确认更新。更新不删除 `%APPDATA%\Folia HiFi`、已有组件配置或备份，不需要重跑 backup。ZIP 请完整解压到新目录。

## 已知问题

**Spotify 经 HQPlayer 输出仍可能出现断续播放，本次未宣称解决。** 三秒实际出声目标与历史偶发 Seek 继续保留观察。软件增益、客户端处理与 HQPlayer DSP 会影响信号，不将整数模式等同于全链路 bit-perfect。

## 验证

更新模块的 13 项针对性测试通过；界面组件、类型检查和桌面构建记录见仓库验证文档。双源真实下载与确认安装的结果在完成后补充，模拟测试不等于实际更新已通过。
