# Folia HiFi 0.7.19 r2 · Spotify 进程专属采集

- 将 Spotify 的采集入口从 VB-CABLE 端点混音替换为 Windows 进程专属回环，只采集绑定的 Spotify 音频进程及子进程。HQPlayer 独占 DAC 后，Windows 默认输出即使回落 VB，也不再因此阻断播放。
- WASAPI、ASIO、HQPlayer 共用新入口；其他应用写入 VB 不再触发无关的隔离拦截。仍保留实际输出回灌、Spotify 进程身份和设备格式检查。
- 修复失败会话暂停后无法重新准备，以及清理错误覆盖原始失败原因；界面显示中文原因并保留错误码。连接向导不再要求先找到额外实体输出。
- 配置、账号与既有备份保留，无需重装 VB-CABLE 或重新 backup。更新前退出旧 Folia，安装 EXE 或将 ZIP 完整解压到新目录。

**系统要求：Spotify 新采集入口需要 Windows 11 x64，所用 API 的最低系统构建号为 20348。普通 Windows 10 不支持该 API；不绑定本机的 28000 内核。** VB-CABLE、Spotify 和 Spicetify 仍是当前 Wrapper 方案的组成部分。

完整 Folia 已验证默认 VB 下启播、WASAPI → HQPlayer、HQPlayer 切歌、HQPlayer → ASIO 与退出恢复；以实际 PCM 交付和输出时钟记录判断，未声称人工听感验证。173 项针对性单测、14 项向导界面及原生测试分组通过。其他机器、Windows 构建和本轮未准备的本地曲库不列为已实测。三秒性能和历史偶发 Seek 保留观察。详见 [验证记录](../PROCESS-CAPTURE-r2-VALIDATION.md)。
