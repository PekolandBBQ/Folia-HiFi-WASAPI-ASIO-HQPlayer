# Folia HiFi 0.7.19 r9 · Spotify / HQPlayer WAV 输入与自然结尾

## 本次更新

- 解决用户报告的 Spotify 经 HQPlayer 输出爆音／断续问题。实时整数 PCM 改用 WAV 封装，修复 HQPlayer 的读取、分段请求、重复读取及请求地址兼容性；不通过重采样或量化改变原 PCM。
- 自然结束时区分采集 EOF 与实际输出结束，等待 HQPlayer 缓冲和 DSP 尾音排空后进入下一首；按实际报告延迟补尾，补齐短曲尾段、自然循环与换歌竞态。清理旧会话不会以旧歌曲身份盲目暂停新歌，歌曲、进程、设备和会话检查保留。
- Folia 启动先到主页，用户明确选择 Spotify 后才准备和握手。Spotify 失联后切换其他音源，旧错误和恢复任务不再拦住新音源；切回 Spotify 再连接与恢复。
- 应用内安装包下载可取消并重新下载，取消会停止请求并清理未完成文件；网络失败后可重试，Gitee 分片仍按原顺序自动合并。下载和取消不打断播放，完整下载后仍须确认才能更新。
- 改善 Spotify 应用输出目标失效时的自动修复；音频链路如实显示客户端解码 PCM 与实际处理路径，未返回的原始编码或音质保持未知。
- 正式发行包纳入 HQPlayer 0.1.4-preview.8 WAV 组件和 Spotify 统一组件清单 revision 9。首次启动升级已知旧 HQPlayer 组件，保留上一版回退和升级记录，清理未被引用的旧组件目录。Spotify 路由／采集来自新安装包，桥接通过版本和能力握手更新；Spicetify 与 VB-CABLE 沿用 Folia 已验证组合，不重复安装同版驱动或重新 backup。
- 主页合并 Spotify 接入、音乐库、推荐、搜索、收藏与歌词说明；HQPlayer 独立连接及流媒体升频分别保留。
