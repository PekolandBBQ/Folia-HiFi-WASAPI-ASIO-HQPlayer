# Folia HiFi 0.7.19 r6 · Spotify 播放同步与更新提示

## 播放修复与改进

- Spotify 桌面换歌时使用 Folia 风格确认框，可选择追随歌曲和进度、暂不追随，或在 Spotify 中继续。修复追随后音频推进但 Folia 进度停住的问题。
- 修复 Spotify 桌面拖动进度条被误认为歌曲结束、意外进入下一首的问题；同曲跳进度沿用当前歌曲和路由。
- 修复 Spotify 主动暂停后被错误恢复播放，以及继续播放时 Folia 未跟随的问题。后台观察器不再把准备播放时的临时暂停当成用户暂停。
- 循环模式与 Spotify 桌面同步：关闭、列表循环、单曲循环；随机播放仍独立设置。自然结束由 Folia 队列协调，避免两端同时切歌。
- 进程采集不再要求 Windows 端点会话先变成非活动状态；保留真实暂停确认、进程身份和采集清理检查。补齐原始失败、清理失败及暂停前后状态日志。

## 更新提示

发现本 fork 新版后，在应用内展示更新说明并询问是否下载；选择“稍后再说”不会下载安装包。安装版下载后由用户确认退出更新，不自动安装，不中断后台播放。沿用 GitHub / Gitee 双源及分片自动合并。

## 下载与保留资料

专版标签 `folia-hifi-v0.7.19-r6`，内部构建 `1792384749744`，应用版本仍为 `0.7.19`。GitHub 提供完整安装包和便携 ZIP；Gitee 提供相同构建的分片及更新清单。应用更新器会自动合并；手动下载需收齐同组 `.001` 起的所有分片，用 7-Zip 打开 `.001` 合并，便携包完整解压到新目录。

更新保留配置及组件备份，不需要重新登录、重装组件或重跑 backup。
