# Folia HiFi 0.7.19 r3 · Spotify 恢复与歌词体验

**已知问题：Spotify 经 HQPlayer 输出目前仍存在断续播放，r3 尚未解决。** 增加预缓冲或降低滤波/整形器负载可能缓解，但不代表根因已修复。三秒性能与历史偶发 Seek 继续观察。

## 本次更新

- 统一进程采集的准备、续播、Seek、输出切换与失败恢复条件，移除旧端点活动会话检查对进程采集的错误拦截；保留精确进程身份、路由所有权和清理检查。
- 短暂状态抖动按可恢复类型静默重试，避免旧失败持续拦住下一次播放；界面显示具体中文原因，诊断日志保留原始错误码、请求来源与最终播放歌曲。
- 修复快速点击歌曲卡片、旧曲结束事件与新请求交错导致的歌曲错位；时长容差与 Wrapper 状态层统一为 1000 毫秒。
- 拼贴页的上一首、下一首及自动切歌留在歌单，定位展开当前歌曲卡片并显示滚动歌词；只有主动进入播放页才跳转。卡片定位仍采用上游最小平移。
- Spotify 原歌词延长等待、取消空结果长期缓存，旧请求的成功/失败结果不覆盖当前歌。确认无歌词时，详情页与卡片显示“当前歌曲无歌词或为纯音乐，请欣赏”；不把加载中或接口失败当作无歌词，也不修改歌曲的纯音乐属性。

## 安装与保留资料

应用版本保持 0.7.19，发行标签为 `folia-hifi-v0.7.19-r3`。更新前自行退出旧 Folia，运行 EXE 安装包或将 ZIP 完整解压到新目录。保留 `%APPDATA%\Folia HiFi` 的账号、配置和原有组件备份，无需重新 backup 或重装驱动。Spotify 桥接更新后，若 Spotify 一直未退出，请正常退出并重新启动 Spotify 一次以加载新扩展。

Spotify 进程采集要求 Windows 11 x64（API 最低构建号 20348）。组件：路由 0.19.0-dev.31、采集 0.1.5-capture.11、原生音频 0.1.3-preview.3、HQPlayer 0.1.4-preview.7。主程序正式发行不改写这些内部组件版本。

本次汇总针对性单元测试 421 项、Node 测试 50 项、无歌词界面测试 3 项通过，类型检查与桌面 renderer/资源图构建通过。无歌词用例覆盖 Paper Plane、In Moments Does Moon Persist、赴大荒的空返回分类、重试及缓存恢复；用户已确认这三首在 Spotify 中也无歌词。
