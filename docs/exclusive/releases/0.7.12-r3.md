# Folia-HiFi-WASAPI-ASIO-HQPlayer-Spotify · 0.7.12 r3

本次基于上一正式版 `hifi-v0.7.12` 加入 Spotify 桌面接入及播放修复。应用版本保持 **0.7.12**，使用独立正式标签 **`folia-hifi-v0.7.12-r3`**，保留上一版发行件。

**Spotify 路由当前限定 Windows x64、内核构建号 10.0.28000；其他构建暂不能启用此路由。** 普通桌面版和 Microsoft Store 版均可检测，本次本机实播使用 Store 版。正式发布标记不改变组件的有限验证范围。

## 新增功能

- **Spotify 接入 Folia**：Wrapper 与 Spicetify 桥接控制用户本机 Spotify，VB-CABLE 实时采集交付给 WASAPI、ASIO、HQPlayer，可使用整数 PCM 模式。HTTP 与 Origin 路线暂时搁置。
- **首次使用组件向导**：检测官网桌面版与 Store 版；未安装时提示用户自行安装、登录。固定版本“一键安装”紧接“一键配置”，复用已有组件、配置和备份。首次 VB-CABLE 安装/重装提示重启，回来重新检查驱动与设备对。
- **实际输出配置指导**：Windows 默认输出落在 CABLE 或无法确认时，引导打开系统声音设置，选择真实扬声器或 DAC。HQPlayer 的 DAC 选择与 Windows 默认输出分别处理。
- **后台拉起与桌面协同**：Folia 点歌可后台启动 Spotify，左下角显示准备进度。桌面直接换歌时自动暂停，用户选择追随歌曲与进度，或交还 Spotify 直接播放；退出或实际切换音源时，可选择是否关闭由 Folia 拉起的 Spotify。
- **封面与原歌词**：已点赞歌曲使用九首歌曲封面的九宫格；可用时回传 Spotify 歌曲自带歌词。
- **短缺口容错**：采集不连续但位置连续时继续交付；已知缺口不超过 100 毫秒时补等长静音再继续原样本，记录补偿帧数。未加入强制跳进度或自动重建，较大/未知缺口仍提示失败。
- **渐进准备与输出续播**：本次接入所需的音频准备、HQPlayer、整数处理和音源切换整合入 fork，保持歌曲、检查点与播放/暂停意图。

## 修复说明

- 修复外部 Spotify 资源布局检查与启动黑屏的处理链，继续已有配置进度。
- 修复 Store 版启动脚本需要的 `StoreActivation.cs` 未被装入程序包，导致客户端启动失败。
- 修复首次 VB-CABLE 安装器未弹出，以及重启后设备验证和实际默认输出指导不足。
- 修复没有获得实际 Spotify 路由时，空值比较导致退出误报“路由恢复失败”。对应整组 8 项清理测试通过。
- 修复暂停后立即 Seek 可能漏发暂停：定位改变位置，不再被误判为替换暂停意图；新的播放意图仍能取消旧暂停。
- 修正设置页历史记录提示结构。旧音量恢复记录保持原文件，不再自动查询或修改 Spotify 音量。
- 将旧音量流程、旧向导和依赖外部机器路径的测试迁移或淘汰，保留历史原文与原因；补齐缺失 Wrapper 集成夹具。当前单测口径与实现一致。

## 安装与使用

1. 选择 EXE 安装版或 ZIP 免安装版。ZIP 完整解压后运行，更新前退出旧版；已有 `%APPDATA%\Folia HiFi` 配置保留。
2. 自行安装 Spotify 并登录。Folia 点击“连接 Spotify”，选择客户端版本。
3. “① 一键安装” → 首次驱动安装后按提示重启 → “重新检查” → Windows 默认输出选实际扬声器/DAC → 按向导退出 Spotify → “② 一键配置”。
4. “启动并连接 Spotify”，就绪后“完成并返回歌单”，在 Folia 点歌。HQPlayer 用户自行安装、授权并配置 Desktop 的 DAC、DSP 和网络控制。

Spotify 内暂停、停止、切歌、Seek、换后端保留路由；暂停/停止关闭采集。仅退出 Folia、实际播放其他流媒体/本地音源，或明确交还 Spotify 时恢复路由。完整步骤见 [使用说明](../USAGE.md)。

主程序与 ZIP 名称沿用本 fork 的 `Folia-HiFi-WASAPI-ASIO-HQPlayer-0.7.12-*` 结构；发行标题追加 Spotify 接入。内部固定组合为 Spicetify 2.45.3、VB-CABLE Pack45/3.3.1.7、路由 0.19.0-dev.25、采集 0.1.5-capture.9、统一组件包 0.1.0-preview.2。原生音频为 0.1.3-preview.2，HQPlayer 组件为 0.1.4-preview.5（保留 .4 回退）。
