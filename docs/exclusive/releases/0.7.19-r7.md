# Folia HiFi 0.7.19 r7 · Spotify 搜索与资源升级修复

## 修复

- 修复 Spotify 更新后仍加载旧页面资源，导致带组件启动时搜索失败的问题。商店版按客户端实际二进制版本识别资源，保留旧配置和备份，为当前版本生成独立资源。
- 搜索页“重试”会完成资源配置、重新建立桥接连接，再执行原搜索；并发请求共用恢复任务，失败后可以再次恢复，不再只重复等待。
- 仅修复页面资源时沿用当前已装配的组件，不要求重装音频组件。正常安装和升级仍检查 Folia 已验证的组件清单；发行包与发布清单保持一致。
- 补齐配置阶段、原始原因和中文提示，避免搜索失败被笼统显示成播放错误。
- 固定打包流程：从最终应用包同步外部脚本，避免复用旧目录时遗漏更新。相关回归加入 PR 检查。

## 下载

专版标签 `folia-hifi-v0.7.19-r7`，内部构建 `1792432691458`，应用版本仍为 `0.7.19`。GitHub 提供完整 EXE 安装包和便携 ZIP；Gitee 提供同一构建的分片和更新清单。应用内下载会自动合并；手动下载需收齐同组分片后，用 7-Zip 打开 `.001`。配置和组件备份保留，无需卸载旧版或重跑已有 backup。

本轮 41 项针对性回归通过，覆盖资源版本变化、修复后重连、原搜索重发、并发恢复、失败后重试、安装升级检查及最终包外部脚本。用户测试后的运行日志确认资源更新到 Spotify 1.3.5.3058、桥接重连成功、在线搜索返回 30 首，并记录搜索结果歌曲进入播放及 PCM 交付。Spotify 自身搜索页面没有独立的界面验收记录，未将其单独列为已验证。
