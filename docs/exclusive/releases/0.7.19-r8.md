# Folia HiFi 0.7.19 r8 · Spotify 音乐库、推荐与分类搜索

## 新增与改善

- Spotify 音乐库补齐自建及收藏的他人歌单、收藏专辑和关注艺人，沿用 Folia 原有分类、拼贴与详情页。歌单文件夹和长列表分页读取，保留已点赞歌曲及本机已加载曲目入口。
- 原有“电台”分类接入 Spotify 当前账号返回的 Daily Mix、每周新发现、新歌雷达等推荐歌单；内容依账号、地区与客户端返回而异，AI DJ 暂不处理。
- 在线搜索增加单曲、艺人、专辑分类。艺人和专辑结果打开对应详情页；分类切换、分页、返回与晚到响应分别处理，不再仅返回单曲。
- 支持关注/取消关注艺人、收藏/取消收藏专辑。操作写入 Spotify，回读确认并刷新完整收藏列表后更新显示；保留歌曲点赞/取消点赞。写入队列与播放、搜索、状态读取分开，失败不冒充成功。
- 改善推荐查询的客户端参数与具体错误记录；把冷启动首次进程发现不足纳入已有的三次恢复预算，保留真实原因、进程身份和清理检查。
- 主页更新使用方法，并补充维护者保存的音乐库、推荐、搜索、详情及歌词实机截图；保留原有音频设置展示和上游署名。

## 已知问题

**Spotify 经 HQPlayer 输出仍可能出现断续播放，本版未解决。** 三秒实际出声目标、历史偶发 Seek 和少数冷启动进程发现等待继续观察。推荐内容不保证每个账号都相同；客户端接口未来变化可能需要适配。
