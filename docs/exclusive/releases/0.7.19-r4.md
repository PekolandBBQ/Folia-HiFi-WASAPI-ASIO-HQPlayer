# Folia HiFi 0.7.19 r4 · Spotify 在线搜索、收藏与自动连接

**已知问题：Spotify 经 HQPlayer 输出仍可能断续播放，本次未解决。三秒性能与历史偶发 Seek 继续观察。**

## 新功能与修复

- Spotify 搜索改为通过 Wrapper 搜索在线曲库，不再局限于已点赞歌单。支持点赞、取消点赞；远端确认成功后重新读取并同步已点赞歌单，不仅修改本地状态。
- 已连接 Spotify 账号时，启动 Folia 自动检查并尝试完成缺失组件安装、配置及连接。复用正常连接；识别旧桥接和未使用配置资源启动的 Spotify，并自动处理重新连接。
- 切换到 Spotify 不反复弹出配置向导。后台首次尝试失败后静默重试三次；打开 Spotify 歌单且仍未连接成功时，才提示具体中文原因。用户仍可主动打开设置。
- 未安装 Spotify 时需用户自行安装并登录；系统管理员授权、驱动安装窗口和 Windows 重启仍需用户操作。已取消的驱动安装不会在每轮静默重试中反复弹出。
- 退出 Folia 不再被路由恢复失败提示阻止。退出时执行有时限的清理，失败或超时保留日志并继续退出；默认保留 Spotify。实际切换音源时的后台 Spotify 询问保留。

## 更新方法

应用版本仍为 0.7.19，fork 标签为 `folia-hifi-v0.7.19-r4`。自行退出旧 Folia，运行 EXE 安装包或把 ZIP 完整解压到新目录；保留 `%APPDATA%\Folia HiFi` 配置和已有备份。无需为了更新手动重跑 backup。无需记住先开 Spotify 还是先开 Folia。

127 项针对性单元测试、48 项 Node 回归、类型检查和桌面 renderer 构建通过。覆盖自动准备步骤、握手、旧桥接/普通启动恢复、远端收藏读回、重试与弹窗条件以及不阻止退出。一次测试夹具将同一模拟进程的启动时间每次刷新，导致身份核对超时；固定夹具生命周期后整组通过，原失败记录保留。
