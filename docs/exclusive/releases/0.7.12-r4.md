# Folia HiFi 0.7.12 r4 · Spotify 跨 Windows 版本自动适配

正式标签：`folia-hifi-v0.7.12-r4`。应用版本保持上游 0.7.12。此修订替代 r3 中的 Spotify 单机构建限制，r3 标签及原附件保留。

## 修复内容

r3 将本机试验准入带进公开包：Folia 和原生组件均只接受 Windows 内核构建 10.0.28000，其他用户无法启用 Spotify。r4 移除这两层固定构建号限制，在用户系统上选择实际可用的已知应用音频接口。Windows 10 接口与 Windows 11 接口分别适配；不会按机器名称、设备 ID 或开发者路径放行。

组件仍为随 Folia 提供的 Windows x64 自包含程序。普通用户无需安装 .NET SDK、Node、Visual Studio，也无需每次 Windows 更新后重新构建。Windows 10（1803 或更新）与 Windows 11 x64 为适配范围；具体系统能否启用，以本机接口检测和播放准备中的真实路由读取为准。x86、ARM 原生包不在本次发行范围。

启动只检查接口，不写音频路由。准备播放时继续验证 Spotify 进程、原始每应用路由、VB-CABLE 端点和音频会话。Windows 不提供所需接口时显示明确提示。运行时兼容结果与历史硬件实测资格分开记录，不把其他 Windows 的模拟接口测试说成实播。

## 使用方法

1. 下载 EXE 安装或解压 ZIP，退出旧 Folia 后使用新程序。配置目录继续使用 Folia HiFi，已有设置不覆盖。
2. 自行安装官网桌面版或 Microsoft Store 版 Spotify 并登录。
3. 在“连接 Spotify”按顺序完成“① 一键安装”“② 一键配置”。已经安装和配置的组件、已有备份继续复用，不重跑 backup。
4. VB-CABLE 首次安装后按提示重启；Windows 默认输出选择实际扬声器或 DAC。完成向导后在 Folia 点 Spotify 歌单歌曲。
5. 选择 WASAPI、ASIO 或 HQPlayer 输出后直接播放。HQPlayer Desktop 需自行安装、授权，配置实际 DAC / DSP 并启用 `Allow control from network`；Spotify 与其他音源使用相同的输出选择。

更多说明见 [使用方法](../USAGE.md)。Spicetify 2.45.3、VB-CABLE Pack45 继续统一固定管理；此版路由组件为 0.19.0-dev.26，采集仍为 0.1.5-capture.9。

## 保留行为

Spotify 的暂停、停止、切歌、Seek 和输出后端切换继续保留来源路由；暂停/停止停止采集。实际播放其他音源、退出 Folia或明确交还 Spotify 时恢复。原始路由的读取、写后回读、退出恢复和短缺口策略保留。Folia 不自动查询或修改 Spotify 音量。桌面换歌后的暂停/追随/交还选项、后台启动、歌单九宫格及原歌词继续保留。

## 验证范围与待观察项

最新自动测试、打包摘要和本机只读接口结果见附件 VALIDATION.json。Windows 10/11 接口选择覆盖多构建号及接口不可用路径；本机实际 28000 可自动识别接口，并通过公开组件装配和真实组件进程 hello/close。未在其他 Windows 系统进行实播，也未因本次兼容修订重跑全套硬件矩阵。Spotify 当时未运行，额外的现存会话读取诊断未满足前提，不能计为播放失败或通过。

此前 route25/capture9 的整数 WASAPI 与退出恢复，以及分阶段 ASIO、HQPlayer、QQ/网易云/本地跨源证据保留原版本和日期，不升级成 route26 的新实播结论。三秒目标与偶发 Seek 继续观察，本次不宣称性能达标。完整干净 Windows 上 Spicetify 首次安装仍待实测。

## 下载及来源

附件保持 fork 的 EXE、ZIP、源码、组件源码、验证记录和 SHA256SUMS 结构。route26/capture9 对应源码单独提供；其他原生音频、HQPlayer 和 FFmpeg 输入与 r3 相同。原生路由接口标识与方法布局核对 [EarTrumpet Windows 10 实现](https://github.com/File-New-Project/EarTrumpet/blob/master/EarTrumpet/Interop/MMDeviceAPI/IAudioPolicyConfigFactoryVariantForDownlevel.cs)及 [Windows 11 实现](https://github.com/File-New-Project/EarTrumpet/blob/master/EarTrumpet/Interop/MMDeviceAPI/IAudioPolicyConfigFactoryVariantFor21H2.cs)。本模块没有引入其音量控制或全局默认输出写入。
