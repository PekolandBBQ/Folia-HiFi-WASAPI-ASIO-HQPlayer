# Folia HiFi 0.7.9 修订 2

专版应用版本与上游基础版本同为 **0.7.9**，发布标签为 `hifi-v0.7.9-r2`，不覆盖上一正式发行件。WASAPI/ASIO 组件为 **0.1.2**，HQPlayer 组件独立升级至 **0.1.2**；两种可选后端各自安装、停用、校验及恢复。

## 更新

- 修复 HQPlayer 准备 RPC 返回不可跨进程复制的连接对象引发“原生音频操作失败”、链路停在准备中的问题。返回可复制的准备状态，保留真实错误码和诊断。
- “应用到当前歌曲”重新建立 DSP 后恢复检查点并自动播放，包括原先暂停的歌曲；官方 Seek 为整秒定位。下一首设置与默认值独立生效。
- HQPlayer 浮窗采用统一的自定义下拉框、明确按钮文字及字体；SDM 采样率使用 `48k x1024` 等单位；默认 DSP 设置同时提供在 HQPlayer 连接页。
- 只维持一个 HQPlayer Desktop 实例；检测到已有实例先询问。默认完整前台启动，可选后台静默。离开 HQPlayer 输出时关闭全部 Desktop 实例，等待设备释放，再恢复浏览器／WASAPI／ASIO。
- 设备从 HQPlayer DSD 回到原生 PCM 时，针对短暂设备不可用执行有界重开，取消及切歌仍可中止。
- 加载进度涵盖下载、缓存、解码与输出准备。有总量显示百分比，否则显示活动进度；布局高 20 像素、距底部 8 像素，避开歌曲浮窗。
- 并行解码更名为兼容模式并默认关闭，严格失败时提供仅当前歌曲或后续保持开启。布尔选项统一为开关。

## 验证与范围

发布前检查包括类型检查、相关单元测试、界面回归、完整依赖安装，以及本地文件、网易云、QQ 音乐的真实硬件播放。覆盖首次／重复／下一首、暂停及播放时应用当前 DSP、HQPlayer 到浏览器／WASAPI／ASIO、前台和静默模式。实际执行结果及 SHA-256 随 Release 附件提供，历史基线不冒充本次测试。

当前硬件环境为 Windows x64、HQPlayer Desktop 6 和 XingCore DAC。接口回报的播放进度及窗口可见性用于自动断言，不能代替主观音质比较。输入输出硬件设备仍需在 HQPlayer 中设置；原生输出仍需完整准备文件，首次等待随下载、DSP 和设备而变，不能保证固定秒数。

完整 `npm ci` 已包含主程序、独立 HQPlayer 组件和 sync-server（含原生 SQLite）。已有依赖告警与审计项保留在验证记录；本次未为消除告警而更新上游依赖。
