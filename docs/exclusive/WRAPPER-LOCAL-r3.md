# Folia HiFi 0.7.12 本地修订 r3 — 播放并发与测试迁移

基于 r37 接入的 r2 最终整合包继续修订。应用版本保持 0.7.12，Wrapper 是 Spotify 主线，HTTP/Origin 搁置。本次仅在本地生成 NSIS 安装包与免安装 ZIP。

## 修复

- 暂停后立即 Seek 不再令待发送的暂停命令失效。暂停是否过期按播放/暂停意图和会话判断，Seek 仅改变位置；新播放意图仍可替换旧暂停。
- 历史 Spotify 音量记录提示改为已有设置区内的说明块，消除额外裸 section；不新增重复导航项。
- r2 的空值所有权比较修复完成整组确认。清理组模拟文件路径改用宿主路径规则，8 项全部通过。

## 验证与测试口径

全量单测：7024 通过、0 失败、2 原有跳过；616 个文件通过、1 原有跳过，无未处理错误。类型检查通过。旧 125 项失败日志保留，测试迁移与淘汰逐组记录在 `test/retired/spotify-r37/README.md`。

退役旧自动静音/音量恢复、旧向导操作和依赖另一台机器路径的测量模型；新测试覆盖当前历史记录保留、Wrapper 向导和关闭/取消所有权。有效的路由、格式、账号、真实层模拟与退出保护继续保留。补回缺失的 Wrapper 夹具，其六项集成测试实际执行通过。

本次执行设备外测试与构建验证，按用户先前“不用复测”指示保留既有实播证据，不将 r2 真机结果改记为 r3 真机通过。短缺口容错仍是已知缺口最多 100 毫秒，未加入强制跳进度或自动重建。采集与路由固定组合仍为 capture.9 / route.dev.25。
