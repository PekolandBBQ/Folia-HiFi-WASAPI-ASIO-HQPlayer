感谢你详细说明合入前提，也谢谢你对草案的审阅。组件化的方向我愿意接受。我平时会长期使用 Folia 听音乐，也是 Hi-Fi 发烧友，也希望在这一方向持续维护和完善功能。

先明确回应三个维护问题：

1. 我愿意跟进主线每周一到两次的更新，负责组件以及 Folia 接入代码的兼容性适配。当播放流程、automix 或本地库接口变化时，我会同步回归。如果某次无法及时修复，希望采用暂时停用不兼容组件、保留浏览器播放的方式，不让这项可选能力阻碍主程序发布。
2. 我愿意响应相关问题，提供经过测试的通用修复。对于缺少实机的冷门设备，会先收集 Issue 中提供的日志、格式协商结果和厂商公开资料，在可用的相似环境中排查；无法复现或缺乏必要资料时，会明确说明支持范围与修复进度，不承诺所有驱动问题都能解决。
3. 我愿意加入贡献者团队，长期负责原生组件和主仓库中对应的接入代码，而不是提交后将维护交给现有团队。

按照你的意见，我已继续调整并更新到个人仓库，目前还没有提交正式 PR：

- 已将辅助程序源码、.NET 构建与组件打包拆到独立仓库；Folia 侧保留安装管理、播放适配和设置入口。去掉了独立应用标识及专用应用打包配置，复用现有音乐库和用户设置。
- 建立了协议 v1 的版本/能力握手、固定版本和 SHA-256 校验、设置内可选安装及停用。普通构建不再编译 .NET 或携带组件。可选 CI 校验流程也已写好；源码仓库现已公开；正式组件发布及分发方式仍待确认，因此生产下载清单暂时留空。
- 将播放失败、deck 重绑、Web Audio 清理等特殊处理限定在原生后端或与其切换的边界，浏览器路径维持原有行为。
- 已在官方 `folia-ffmpeg-build` 的本地副本中补上 PCM24 编码，同时为可选整数路径补上 PCM32 编码。宿主调用已有的 FFmpeg 位置，移除了 Gyan 的额外构建/下载逻辑。这份补丁已本地编译和验证，尚未合并或发布到官方构建仓库。
- 补充了 WASAPI PCM WAVEFORMATEXTENSIBLE 协商；设备不支持时明确报错，不静默改采样率或降为共享模式。
- 收窄了引擎释放范围：设备枚举、参数错误和旧会话请求不会直接释放正在播放的引擎。
- 原生路径保留 Folia 的 ReplayGain 设置、曲目/专辑模式和峰值保护计算，没有改变现有默认。整数模式下也保留 ReplayGain、软件音量和静音，使用定点整数增益处理；只有合并增益为 1 时才保持准备后的 PCM 采样值不变，不将整数模式等同于全链路 bit-perfect。

首阶段希望限定为 Windows x64 系统下实现本地文件和现有在线音源通过 WASAPI 独占/ASIO 播放、基本播放控制、歌词同步和设备选择，并将“整数模式”和“音频链路展示”作为默认关闭的可选开关一并供审查。音频链路展示会报告实际读取的源规格和引擎回报的格式/增益。

另外想明确补充首阶段的审查范围：希望保留自用分支已实现的在线音源通过 WASAPI 独占/ASIO 原生输出，继续采用“完整准备音频文件后播放”，后续也将考虑加入流式播放。在线歌曲的账号、权限、音质选择和 URL/缓存解析仍复用 Folia 现有流程；宿主负责完整下载或读取缓存、解码准备，再把本地 PCM 交给独立组件。组件不接触流媒体账号或提供商 API。切歌和停止会取消旧准备任务，不使用不完整文件播放；这会增加首次播放等待和临时磁盘占用，也不承诺无缝播放，我个人在家庭宽带环境下多数时候没有明显感到等待，实际等待仍取决于音源大小、网络及解码耗时。这个范围相较最初的本地播放询问有所扩大，希望与你明确确认。

已有的 HQPlayer 及其他探索仍留在自用分支，不纳入首阶段；Linux/macOS 先保留原有 Web 播放方式，将来若扩展再单独讨论对应平台的后端。

目前有完整自动化记录的是在 XingCore 上验证了 WASAPI 和 ASIO 的 44.1/48/96 kHz、兼容/整数两种模式，共 12 组静音测试，涵盖控制、时钟、ReplayGain、结束/重播和错误隔离。实际 Electron 的安装校验、preload、IPC、文件准备和硬件播放链路也已跑通。另有整数边界采样与 FLAC 解码精度测试、组件安装校验测试和界面测试。使用 HTTP 提供的 96 kHz/24-bit 文件，在真实 Electron 中验证了 WASAPI/ASIO 的兼容与整数模式及缓存切换。拓品 USB 和通用 ASIO 驱动另有个人使用测试反馈，暂不将其等同于前述完整测试矩阵或所有设备的兼容性保证。

如果上述包含在线完整准备播放的范围符合你的预期，我希望先与你确认协议 RFC、组件发布/分发方式和首阶段审查边界，再整理正式提交。正式开放安装前，还需要完成独立组件发布，以及官方 FFmpeg 编码补丁的合并、发版和主程序固定版本更新。
